# Верстка лендоса на чистом css

Особенности:
1. Классы именуются без БЭМ методологии.
2. У h3 использован атрибут data-title, чтобы стилизовать псевдоэлемент заголовка с прозрачным текстом.
3. Квадратным элементам применяется свойсвто aspect-ratio: 1.

Спасибо [Александру Ламкову](https://www.youtube.com/@AleksanderLamkov) за мастер-класс!
