# Верстка лендоса на чистом css

Особенности:
1. Классы именуются без БЭМ методологии.
2. У h3.motivation-card-title использован атрибут data-title, чтобы стилизовать псевдоэлемент заголовка с прозрачным текстом.
3. Размеры заголовков часто заданы через clamp().
4. Квадратным элементам применяется свойсвто aspect-ratio: 1.
5. У элемента training-types-item использована локальная переменная с размером иконки на заднем фоне, и переопределена на медиазапросе 767px.
6. Внутри формы использован тег header, оборачивающий заголовок и подзаголовок.
